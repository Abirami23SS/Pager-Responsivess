# Product Overview — Syncfusion Blazor Components

## Summary

**Syncfusion.Blazor** (`Syncfusion.Blazor` NuGet package) is an enterprise-grade, native Blazor UI component library providing **100+ production-ready components** for building modern web applications on .NET 8, 9, and 10. Every component is authored in C# and Razor — no JavaScript wrapper overhead.

**Current version:** 32.1.19  
**Package ID:** `Syncfusion.Blazor`  
**NuGet:** https://www.nuget.org/packages/Syncfusion.Blazor  
**Docs:** https://blazor.syncfusion.com/documentation/

---

## Scope

| Area | Components |
|---|---|
| Data Management | Grid, TreeGrid, PivotView |
| Charts & Visualization | Charts (50+ types), 3D Charts, BulletChart, Sparkline, StockChart, CircularGauge, LinearGauge, HeatMap, TreeMap, Sankey |
| Editing | RichTextEditor, DocumentEditor, Spreadsheet, BlockEditor, MarkdownConverter |
| Inputs & Forms | DataForm, TextBox, Numeric, ColorPicker, DatePicker, FileUpload, Signature, OTP |
| Navigation | Menu, Toolbar, Ribbon, Tabs, Accordion, Sidebar, Breadcrumb, TreeView |
| Layout | Dashboard, Dialog, Splitter, Card |
| Calendars & Scheduling | Calendar, DateRangePicker, Scheduler, Gantt |
| DropDowns & Lists | DropDownList, MultiSelect, AutoComplete, ComboBox, MultiColumnComboBox, ListBox |
| File Management | FileManager (Azure, AWS, SQL, Physical) |
| Interactive & AI | InteractiveChat, SmartPdfViewer, SmartRichTextEditor, ChartWizard |
| Specialized | QueryBuilder, Kanban, InPlaceEditor, ImageEditor, BarcodeGenerator, Diagram |

## Primary Audience

- **Enterprise application developers** building line-of-business apps
- **SaaS product teams** requiring rich, data-intensive UIs
- **.NET migration teams** modernising legacy applications to Blazor
- **Internal Syncfusion contributors** maintaining and extending the library

---

## Render Mode Support

All components are designed to work across all Blazor hosting and render modes:

| Mode | Status |
|---|---|
| Blazor Server (Interactive) | ✅ Fully supported |
| Blazor WebAssembly (WASM) | ✅ Fully supported |
| Blazor Auto | ✅ Fully supported |
| Static SSR | ⚠️ Non-interactive components only |
